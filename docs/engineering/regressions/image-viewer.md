# 看图：生命周期与回归

## 变更前影响分析

1. 根因与目标：MacPilot 没有文档查看器；独立看图应用的进程级缓存不能直接搬进常驻工具箱。
2. 历史规则：`win-001-main-window-opener`、`win-002-login-startup-readiness`、`cfg-001-downgrade-wipe`、`upd-001-designated-requirement`。
3. 旧修复边界：保留晚启动、设置窗口抬升和签名流程。文件路由单独缓冲到配置就绪；看图新增启用列表值，不新增或收紧配置键。
4. 影响面：首页和侧栏、应用菜单和状态菜单、Finder/LaunchServices 冷热打开、配置、退出和打包。截图 URL scheme 仍走原通道。
5. 验证：索引增补触发完整安全套件；重点检查启动、配置、菜单、截图、签名及全部看图套件。
6. 新增测试：资源分层和关闭竞态、解码与预算、文件夹订阅、窗口状态、打开路由、配置默认值。
7. 实机：已安装版本升级降级、从 Finder 冷热打开、混合 DPI/全屏/打印和 Instruments 资源验收，都不能由自动化替代。

## 不变量

- 关闭只存在轻量代理；开启只创建 Runtime；显式打开文件或文件夹才建立资源会话。空文件夹结果不留下会话。
- 最后一个窗口关闭或功能关闭须撤销队列、索引订阅、动画帧、压力监听和缓存。过期结果不得更新窗口或重新建立会话。
- 文件夹索引不递归；同目录索引在活动订阅间共享，撤销最后一个订阅即取消。解码能力以 ImageIO/PDF 实际结果为准。
- Finder 文件不作为深链广播，不修改默认应用；功能关闭时只显示启用提示。窗口命令不使用全局按键监听。
