# 截图审查与滚动长截图（2026-10-04）

审查范围：截图设置与输出、框选工具栏、单帧采集、滚动采样、垂直拼接及相关测试。仓库原有滚动截图快捷入口，本次补齐常规框选入口、手动采样及可靠的完成/取消行为。

## 已修复的问题

1. **P1：完成与采样存在竞态。** 原实现完成时立即读取帧数组，180ms 防抖中的最后一帧及正在进行的截图可能丢失，完成期间还能继续追加。现在会停止滚轮监听、等待正在采集的帧，并采集最终画面后再拼接。
2. **P1：无法匹配时直接整帧追加。** 无重叠、反向滚动或跨度过大会产生重复或缺失的内容。现在不接纳无法匹配的帧，提示滚回后小幅向下滚动；最终画面不能匹配时保留会话供重试。
3. **P2：相同画面被追加。** 原算法排除了完整重叠，停在页面底部继续滚动会消耗预算并使输出变长。现在识别完整重叠，重复采样不增长帧数。
4. **P2：取消没有隔离异步结果。** 原实现只取消防抖任务，已经进入采集/拼接的任务仍可能输出。现在所有异步阶段检查会话关闭状态，取消后丢弃结果并释放帧列表。
5. **P2：控制条可能进入截图。** 靠近显示器边缘时悬浮条可能盖住选区。采集期间隐藏控制条，采集后恢复，不排除其他 MacPilot 窗口。
6. **P2：原始宽度校验不足。** 超过 256 像素的不同宽度都会缩成相同宽度，可能被误认为可匹配。现在先校验原始宽度，并增加重叠条带采样密度。

## 使用方式

- 在截图设置中选择「滚动长截图」，或普通框选完成后选择「更多 → 滚动长截图」。
- 只框选滚动内容，尽量避开固定标题、工具栏、滚动条及动画。缓慢向下滚动，保留相邻画面的重叠部分。
- 自动采样未触发时，点击「采集当前画面」。无需自动控制目标应用或增加辅助功能权限。
- 点击「完成」后按现有保存、复制、快速访问和贴图设置处理，长图使用 PNG 保留文字清晰度。
- 上限为 30 帧或 256 MiB 原始帧数据；达到上限后只输出已接纳的部分。输出画布也检查 256 MiB 上限。

## 验证与边界

自动测试覆盖逐行像素顺序、重复帧、无重叠、原始宽度不一致、预算、错误后重试、采样中取消、完成时等待最后一帧，以及工具栏路由。配置键和快捷键保持兼容。

验证结果：`swift test --no-parallel` 的 1085 项测试、127 个套件全部通过；全新 scratch 目录下的 `swift build -c release -Xswiftc -warnings-as-errors` 通过。并行全量运行出现 CPU/BLE/快捷键时序、闭盖重连、配对窗口超时及共享后台任务计数争用；后面三项也单独复核通过，串行全量运行未复现。

此功能是用户手动滚动、自动采样的纵向拼接，不自动滚动应用，不支持横向长图。固定栏、动态内容和重复图案可能影响匹配；用户应只选择稳定的内容区域。
