## 已实现的恢复边界

- 显示拓扑：创建意图先落盘，得到虚拟屏 UUID 后立即提交并同步到磁盘，再等待可用。等待超时保留 UUID；UUID 提交失败只尝试安全清理，并阻止后续控制覆盖未提交目标。恢复先提交 restoring 阶段，可用屏幕分别恢复，离线目标留在日志中。只有原始布局、主屏和虚拟屏移除经过验证，且随后稳定检查通过，才删除日志。
- 跨会话：通过真实 UUID 重新枚举当前显示 ID。桥接层 `cg-...` 是会话内的后备标识，不能跨登录会话授权修改或将旧日志重新绑定到新会话。没有句柄的残留虚拟屏明确提示人工恢复，不能假装销毁成功；已经不存在的虚拟屏视为已移除。
- 热插拔：禁用、保留单屏和虚拟屏确认共用扩展快照入口，先保存新目标原始布局。generation、远程会话和有效租约共用校验；本机紧急恢复不受过期远程租约阻断。
- 黑屏：v4 快照保留历史字段，追加 UUID、原始状态、操作意图、恢复次数和错误。每次硬件操作前原子保存并刷新日志。亮度、DDC 电源和键盘背光恢复要读回确认；离线或未确认的设备继续保留。未知 DDC 原始电源状态不授权发送关电命令，使用已有亮度能力或遮罩。一个有界重试任务负责重试，耗尽后保留日志和必要的重连观察。
- XPC：短状态/心跳 4 秒、普通控制 15 秒、创建 30 秒、恢复 60 秒。修改命令以 operationID 写入独立操作账本，入队后立即返回 accepted，客户端查询同一 ID，最终结果才作为完成。客户端等待上限 90 秒；超时不等于底层失败，也不重发修改命令。Helper 重启先做拓扑恢复，再将未完成操作标记 interrupted，不重做创建。账本保留当前 generation 可重放的 ID，不以容量淘汰；满额时拒绝新修改，另预留一个恢复槽位。旧 generation 的终态可淘汰，查询返回 operationUnknown；旧协议无操作 ID 仍走同步路径。
- BLE：反向 GATT challenge 用 Mac 的 ContinuousClock 计时（包含休眠时间）；已认证的手机时间仅用于诊断。HMAC、Mac/配对身份、nonce 一次性消费、RSSI 范围及过期拒绝保持有效。历史协议验证 API 继续兼容，生产入口使用本地 challenge。
- Quick Search：输入变化立即撤销上一代、取消查询并清除文件结果。回调同时核对代次、运行状态和面板可见性。空查询继续按收藏、最近使用、其余索引应用回填，最多 50 条；运行状态同步不额外添加结果。
- Local Ports：身份由 PID、UID、内核启动秒/微秒和绝对可执行路径组成；读取路径前后再次核对内核身份。发送 TERM 或显式 KILL 前均重新扫描所有权和身份。普通超时不会自动升级 KILL。macOS 的身份检查与 kill 之间仍存在无法原子消除的窗口。
- 主窗口：应用持有轻量打开协调器和实际 NSWindow，关闭只卸载 ContentView；菜单、Dock 和应用重开通知独立于视图订阅。窗口尚未连接时合并打开请求，重复打开复用原窗口。

## 真实 Mac 验收（尚待执行）

模拟测试不能确认 WindowServer、私有显示 API、具体显示器 DDC 行为或真实 SwiftUI 场景重开。以下项目必须在获准的隔离环境及真实设备上完成，不能将自动化通过视为已完成：

- 内置屏和外接屏分别黑屏、输入唤醒、原始亮度与键盘自动背光读回。
- DDC 不响应、写入成功但无法确认、黑屏期间强制终止及重启恢复。
- 活动事务中插入新屏，再禁用或切换为虚拟屏；拔出待恢复屏幕后确认其他屏仍恢复，重新接入后继续恢复。
- Helper 异常退出与重启、跨登录会话、残留虚拟屏句柄丢失；确认不会关闭最后一个可用实体屏，也不会吞掉恢复错误。
- 系统休眠与唤醒后恢复状态、最后一个功能租约结束后的 Helper 安全退出。
- 主窗口关闭后菜单栏、Dock、Finder 重开，连续关闭重开，以及隐藏窗口重复打开；确认只有一个窗口且内容可重建。

验收前记录显示器 UUID/布局、亮度和原始电源状态；每个故障场景结束后读回核对。需要黑屏、锁屏或休眠时，必须先取得用户对具体操作的授权，优先使用 AgentSpace 隔离会话。本次未操作用户正在运行的 MacPilot 或替换 /Applications/MacPilot.app。
