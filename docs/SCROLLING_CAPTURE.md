# 滚动长截图

MacPilot 使用 Snapzy 的拼接核心（`224afa560f54d868376b84d0761539f289c08ffb`），
保留原有区域选择、截图输出、历史和快捷面板流程。

## 采集与拼接

- 选择移动的正文区域后，非交互边框标明选区，侧边预览只显示已接受的拼接内容。
- 单屏选区复用一个 15 FPS 的区域 ScreenCaptureKit 流；排除 MacPilot 自身窗口，隐藏鼠标。
  输出尺寸沿用初始截图，保留原生显示缩放，不强制 2 倍。
- 流失败、停滞或跨屏时使用原有静态截图/多屏合成；完成时始终补采实际最终画面。
- 垂直滚动期间每 90 ms 至多请求一次拼接，滚动停下 120 ms 后再补采。
  一个采集正在处理时，后续请求合并为一个待处理请求，不丢弃最新视口。
- `ScrollingCaptureProcessor` actor 串行拥有拼接器；主线程只保存最新流帧、缩略图和状态。
- Snapzy 的行/块匹配及 Vision 注册用于对齐，固定页头、页尾和侧边区域不参与正文匹配。
  固定顶部/底部会从正文输出中裁掉；请优先只框选移动内容。
- 第一个有效移动锁定向上或向下的方向；向上新增条带放在输出顶部，保持文档顺序。
- 对齐失败保留已接受的内容并提示恢复；静止/底部重复画面不增加帧数。
- 接受的全尺寸栅格受 256 MiB 和 30 帧预算约束，输出另受 256 MiB 与 32768 px 高度约束。
  这些是存储/输出预算，不是整个进程峰值内存的保证。
- 实时预览直接从接受的条带渲染，最多 440×840 px；完整长图只在完成时生成。
- 取消会关闭流、窗口和任务，忽略迟到结果；完成失败保留会话供恢复重试。

## 验证

自动回归：`swift test --filter ScrollingCaptureTests`。覆盖像素顺序、上下方向、固定顶部/
底部、重复帧、对齐恢复、并发请求、最后画面、预览和高度预算、异步取消。

界面与真实屏幕验收（自动测试不替代这些检查）：

1. 在浏览器/文档中只框选正文，持续缓慢滚动，观察侧边预览增长，完成后核对首尾行。
2. 包含固定页头/页尾的选区应得到没有重复固定区域的正文长图。
3. 连续滚动后立即完成，核对最后可见正文；超快滚动失去重叠时应提示恢复。
4. 采集中取消、关闭 HUD、拼接时取消，都不应输出文件或留下预览/捕获流。
5. 在 1×、Retina、外接及跨屏选区验证清晰度、坐标与静态回退。
6. 核对深浅模式、HUD/预览位置，以及复制、保存、历史与快捷面板。
