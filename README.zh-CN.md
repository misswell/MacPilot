# MacPilot

[English](README.md)

MacPilot 是一套原生 macOS 菜单栏工具，涵盖自动化、屏幕采集、窗口切换和系统管理。应用共有 **18 个可独立启用的功能模块**；可在首页逐项开关，关闭后该功能会停止自己的快捷键和后台监控。

需要 macOS 14 或更新版本。正式版本提供 Apple 芯片（`arm64`）和 Intel（`x86_64`）构建。

## 功能

### 自动化与控制

#### 应用闲置规则

- 按应用设置闲置时长，并选择自动隐藏应用、关闭窗口但保留进程，或退出应用。
- 可再设置一段隐藏时长，应用持续隐藏后自动退出。
- 可在 MacPilot 设置中导入已有的 Quitter 规则。

#### 登录后启动应用

- 为需要启动的应用分别设置登录后的启动延迟。
- 可选择启动后显示在前台、保持隐藏，或关闭其窗口。
- MacPilot 自身的「登录时启动」开关与这些逐应用启动规则相互独立。

#### 保持唤醒

- 手动开启限时或不限时的保持唤醒会话，也可设置 MacPilot 启动或 Mac 从睡眠唤醒时自动开始默认会话。
- 可按指定应用或进程、电源适配器和充电状态、电池电量、外接显示器或屏幕镜像状态自动开启或结束会话。
- 可选择 Mac 睡眠期间是否继续计算会话时长，并设置电量保护。
- 可分别配置显示器睡眠、显示器关闭后的系统睡眠、屏幕保护程序和合盖运行行为。
- MacBook 合盖后继续运行，需要在系统设置中批准 MacPilot 的后台电源服务。

#### BLE 距离锁定与解锁

- 通过已添加的低功耗蓝牙设备判断接近程度，并为自动锁定和解锁分别设置蓝牙信号阈值与延迟。
- 可设置接近时唤醒、暂停正在播放的媒体、启用屏幕保护程序或关闭屏幕；也可启用被动模式，或从菜单栏立即锁定。
- 可管理追踪设备并查看屏幕锁定记录。Mac 登录密码保存在钥匙串中；设备需要使用稳定的蓝牙地址才能可靠追踪。

#### iPhone 遥控

- 使用短时有效的配对码连接 iPhone，之后可远程锁定 Mac、关闭显示器、解锁或唤醒并解锁，并调整屏幕亮度和输出音量。
- 可通过局域网或蓝牙建立连接，并在设置中管理已配对设备、Mac 显示名称和连接状态。
- Mac 登录密码保存在 Mac 本机钥匙串中，不会发送到 iPhone。

#### 输入法自动化

- 按应用或浏览器网站自动切换 macOS 输入法。
- 按应用设置英文标点，以及标准功能键或媒体键模式。
- 使用全局快捷键循环切换输入法，也可添加自定义快捷键；切换提示可显示在鼠标附近或屏幕中央，并调整显示时长。

### 窗口与输入工具

#### 窗口切换器

- 按 `Option-Tab` 在不同应用的窗口间切换；按住 Option 可继续循环，`Shift-Tab` 向后选择，松开 Option 聚焦选中窗口，按 Escape 取消。
- 可显示窗口标题和预览，并选择是否包含隐藏或最小化窗口。

#### 平滑滚动

- 将鼠标滚轮输入转换为接近触控板的连续滚动。
- 调整滚动方向和速度，也可按应用排除，保留原有滚轮行为。

### 截图与录制

#### 截图与快捷操作

- 自动识别界面元素，也可截取应用窗口、当前窗口、选定区域或整个屏幕；可选择是否包含所有显示器和鼠标指针。
- 支持延迟截图、重复上次选区、滚动长截图、抠取前景物体，以及在框选时直接打开标注工具栏。
- 可用形状、画笔、箭头、文字、序号、模糊和聚光灯标注；支持 OCR 识别并复制文字。
- 截图可复制、保存、置顶贴图，或放入快捷操作面板；可在面板中编辑、移除或管理最近的截图。
- 可查看最近的截图、视频和 GIF 记录；在 Finder 中定位图片文件或从记录中移除条目。快捷操作面板支持自定义按钮、操作快捷键和滑动行为，也可将内容拖到其他应用。
- 截图模式均可设置快捷键。图片可保存为 HEIC、JPEG 或 PNG，并可调整质量和保存目录。
- 可选配置 GitHub 或 Gitee 仓库，用于上传截图并获取图片链接。
- 支持定时截图，可分别设置活跃时段与空闲时段的截图间隔、运行时间段、图片格式和保留天数。

#### 屏幕录制

- 录制框选区域、应用窗口、全屏或纯音频。录制期间可暂停、继续、停止或取消，也可设置倒计时和自动停止时间。
- 配置视频格式、帧率、H.264 或 HEVC 编码、画质、背景、鼠标指针、Retina 分辨率、HDR，以及受支持模式下的透明通道。
- 可录制系统声音和指定麦克风，设置音质，并选择是否把麦克风音频保留为独立音轨。
- 可叠加摄像头画面，或录制受支持的 iPhone/iPad 采集设备画面；可高亮鼠标并显示录制放大镜。
- 可启用录制准备条和悬浮控制条，隐藏桌面文件或控制中心，选择是否录入菜单栏和 MacPilot，防止显示器睡眠，并排除指定应用。
- 可设置录制文件夹和录制快捷键；录制结束后可预览，并将最近一次录制导出为 GIF，调整 GIF 帧率和宽度。

#### 画中画

- 将窗口或选定屏幕区域作为实时悬浮面板显示，并可在不同桌面空间中继续查看。
- 可移动、调整面板大小、缩放画面；适用时可使用媒体控制。

### 日常效率工具

#### 剪贴板历史

- 搜索近期复制的文本、图片、链接和文件；可设置历史条目数量、固定常用内容，并将固定内容置顶。
- 使用自定义快捷键打开面板、预览条目，并选择单击时复制还是粘贴。配合修饰键单击可执行复制、粘贴或无格式粘贴。
- 可选择清空历史记录时是否同时清空系统剪贴板。

#### 访达右键菜单

- 在 Finder 右键菜单中添加复制路径、用指定应用打开、在终端中打开，以及显示或隐藏文件等操作。
- 可按文件类型配置应用和操作；可使用可编辑模板新建文件，并把常用目录加入「常用文件夹」菜单。
- 需要在 macOS 设置中启用 Finder 扩展；使用自选目录时，按系统提示授予文件夹访问权限。

#### Dock 分组

- 创建命名的应用分组，可从应用选择器添加应用，也可把应用拖入分组。
- 每个分组可生成独立 Dock Helper，选择图标样式后把 Helper 加入 Dock，即可从 Dock 打开分组面板。
- 分组面板支持网格或列表布局、显示应用运行状态、调整应用顺序；点击应用可启动它，或切换到已运行的窗口。

### 系统工具

#### 内存监控

- 查看物理内存、已用内存、应用占用、有线内存、压缩内存、缓存、交换空间，以及内存压力和系统运行时间。
- 搜索应用、展开查看相关进程，并选择自动刷新或手动刷新应用占用数据。

#### CPU 监控

- 查看总 CPU、用户态、系统态、nice 和空闲占用、逻辑核心数量，以及 1、5、15 分钟负载均值。
- 搜索应用及其进程占用，选择自动刷新或手动刷新。

#### 本地端口

- 扫描正在监听的本地网络服务，查看端口、所属进程，以及服务是否可从局域网访问。
- 将可识别的项目服务与其他进程分组，搜索和查看详情，并停止符合条件且由你启动的服务。
- 可从菜单栏快速查看服务摘要，再打开完整端口列表进行管理。

#### 存储压缩

- 选择需要监控的目录和文件扩展名，并设置最小文件大小、文件保持不变的时长，以及压缩至少需要节省的空间比例。
- 可自动压缩符合条件且长期未修改的文件，也可手动扫描、查看候选文件、检查压缩结果，并在需要时恢复文件。
- 使用 macOS 文件系统压缩；在支持的 APFS 或 HFS+ 卷上工作，文件仍可由普通应用读取。

## 菜单栏与应用设置

菜单栏可快速管理当前保持唤醒会话、立即执行 BLE 锁定、切换输入法、打开窗口切换器和剪贴板面板、开始智能截图、捕获画中画窗口，以及控制屏幕录制。菜单栏还提供内存、CPU 和本地端口摘要、关闭显示器、更新状态，以及查看 MacPilot 资源占用和后台任务的诊断面板。关闭显示器时当前会话继续运行，用户输入后会重新点亮显示器；在支持的 Mac 上，MacPilot 还会调暗键盘背光，并在显示器唤醒后恢复原来的设置。

应用设置可逐项启用或关闭功能、设置 MacPilot 登录时启动、选择界面语言、查看或在 Finder 中定位配置文件、导入 Quitter 规则，以及检查和安装更新。可单独启用或关闭自动检查更新。

## 权限与本地数据

首次使用部分功能时，macOS 会按需请求隐私权限：

- **辅助功能：** 跨应用操作、模拟按键和全局快捷键。
- **屏幕录制：** 截图、屏幕录制和窗口预览。
- **蓝牙：** BLE 距离功能和 iPhone 遥控的蓝牙连接方式。
- **本地网络：** 通过局域网连接 iPhone 遥控。
- **麦克风和摄像头：** 录制对应的输入源。
- **Finder 扩展和文件夹访问：** 显示 Finder 右键操作和访问选定目录。
- **后台电源服务：** MacBook 合盖后继续保持唤醒。

主程序规则和功能设置保存在 `~/Library/Application Support/MacPilot/config.json`；Finder 扩展单独保存右键菜单配置。Mac 登录密码和设备配对凭据保存在 macOS 钥匙串中。截图托管是可选功能，上传目标为用户自行配置的仓库。

## 下载

从 [GitHub Releases](https://github.com/misswell/MacPilot/releases/latest) 下载最新的 Apple 公证版本。Apple 芯片 Mac 选择 **Apple Silicon（`arm64`）**，Intel Mac 选择 **Intel（`x86_64`）**。解压后先将 MacPilot 移入「应用程序」文件夹，再授予隐私权限。

## 从源码构建

项目使用 Swift 6 和 Swift Package Manager。请在 macOS 14 或更新版本、已安装 Xcode 命令行工具的 Mac 上运行：

```sh
swift build
```

要在本机组装 `MacPilot.app` 应用包，运行：

```sh
./Scripts/build-app.sh
```
