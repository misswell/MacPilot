# MacPilot

[English](README.md)

MacPilot 是一款原生 macOS 菜单栏工具集，提供日常自动化、窗口管理、屏幕采集和系统实用工具。你可以按需启用功能；关闭的功能会停止自己的快捷键和后台监控。

## 功能

### 应用自动化与控制

- **应用规则：** 为每个应用设置闲置规则，自动隐藏应用、关闭窗口但保留进程，或退出应用；也可以设置应用隐藏一段时间后退出。
- **登录后启动：** 为应用分别设置登录后的启动延迟，并选择显示在前台、保持隐藏，或启动后关闭窗口。
- **保持唤醒：** 手动开启保持唤醒会话，也可根据应用、进程、电源或显示器状态自动启动。可设置电量保护；MacBook 合盖后继续运行需要在系统设置中允许 MacPilot 后台电源服务。
- **BLE 解锁：** 根据低功耗蓝牙设备的接近程度自动锁定或解锁 Mac，并设置锁定与解锁距离、延迟等行为。设备需要使用稳定的蓝牙地址才能可靠追踪。
- **iPhone 遥控：** 与 iPhone 配套应用配对后，可在同一局域网中远程锁定、关闭显示器、解锁或唤醒并解锁 Mac。Mac 登录密码始终保存在 Mac 本机。

### 输入与窗口切换

- **输入法自动化：** 按应用或浏览器网站自动切换输入法；也可按应用设置英文标点、功能键模式，并通过屏幕提示或快捷键手动切换。
- **窗口切换器：** 按 Option-Tab 在不同应用的窗口间切换，可显示标题和预览，也可包含隐藏或最小化的窗口。
- **平滑滚动：** 将鼠标滚轮转换为连续滚动，可调整方向、速度，并按应用排除不需要平滑的滚动。

### 屏幕采集与专注

- **截图：** 截取界面元素、窗口、选区或全屏；支持标注、文字识别（OCR）、滚动长截图和窗口置顶贴图。
- **屏幕录制：** 录制屏幕、窗口或选区，可按需录入系统声音、麦克风、摄像头画面及 iPhone 或 iPad 画面。
- **画中画：** 将窗口或选定区域作为实时悬浮画面显示在不同桌面空间中，并支持缩放和媒体控制。

### 日常工具

- **剪贴板历史：** 搜索近期复制的文本、图片、链接和文件，固定常用记录，并在需要时再次粘贴。
- **访达右键菜单：** 添加可配置的快捷操作，例如复制路径、选择应用打开、使用终端、管理文件显示状态、新建文件和打开常用目录。
- **Dock 分组：** 将相关应用整理成分组并从 macOS Dock 打开；点击应用即可切换到已打开的应用，或启动尚未运行的应用。

### 系统工具

- **内存与 CPU 监控：** 查看各应用的内存或 CPU 使用情况，同一应用的相关进程会合并显示。
- **本地端口：** 查看正在监听网络的服务，识别相关项目和进程，并停止符合条件且由你启动的服务。
- **存储压缩：** 使用 macOS 文件系统压缩减少稳定文本类文件的磁盘占用。文件仍可由普通应用读取，也可以恢复。

## 权限与设置

MacPilot 需要 macOS 14 或更新版本。部分功能需要相应的 macOS 隐私权限：跨应用操作和快捷键需要辅助功能权限，屏幕采集与窗口预览需要屏幕录制权限，BLE 解锁需要蓝牙权限，录制麦克风声音需要麦克风权限。合盖保持唤醒需要在系统设置中允许后台电源服务。

应用规则和偏好保存在当前用户账户中，更新 MacPilot 后仍会保留。BLE 解锁使用的登录密码保存在 macOS 钥匙串中。
