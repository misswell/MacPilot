# MacPilot

[English](README.md)

MacPilot 是一款原生 macOS 菜单栏应用，以极小的体积和极低的内存占用常驻运行。它会按照你为每个应用设置的规则，在应用闲置后自动隐藏、关闭窗口或退出，帮助减少邮件、聊天、社交和浏览器应用带来的干扰。

## 功能

- 为每个应用单独设置规则：
  - 闲置一段时间后隐藏；
  - 闲置一段时间后关闭可关闭窗口，但保留后台进程；
  - 闲置一段时间后退出；
- 被隐藏一段时间后退出。
- 为每个应用设置登录后的延迟启动时间（秒），并选择启动后显示到前台、隐藏，或在 10 秒启动宽限期后关闭窗口但保留后台进程。
- 在规则列表中显示最近一次即将触发的退出倒计时（分钟级）。
- 在启动列表中显示秒级倒计时；已运行的应用会自动跳过。
- 可从正在运行的应用中选择、从磁盘选择 `.app`，或直接把应用拖入窗口。
- 支持编辑、删除、排序、启用或暂停单条规则。
- 支持退出规则与启动规则的独立总开关、菜单栏控制、登录时启动。
- 支持跟随系统、English、简体中文三种界面语言。
- 极小的应用体积和极低的常驻内存占用；不携带跨平台运行时，功能也可以独立启停。
- 规则与偏好会保存到本机，更新或替换 App 后不会丢失。
- **本地端口**：查看本机监听端口、识别所属项目和进程，并安全停止遗留的开发服务。

## BLE 解锁

MacPilot 还可以根据最多两台蓝牙低功耗（BLE）设备的接近程度自动锁定和解锁 Mac--支持 iPhone、Apple Watch，或任何使用**固定 MAC 地址**周期性广播信号的 BLE 设备。

在侧边栏或菜单栏中打开 **BLE 解锁**，然后：

- 扫描附近设备并选择你的设备。设备会显示名称、解析出的 MAC 地址和实时 RSSI。
- 可选再添加第二台设备，并选择**任意一台**或**两台设备都**在范围内时保持解锁。
- 设置 **解锁 RSSI**（设备靠近时解锁）和 **锁定 RSSI**（设备远离时锁定），两者可分别禁用。
- 设置 **锁定延迟**（设备离开后的宽限期）和 **无信号超时**（信号丢失后锁定）。
- 可选：接近时唤醒、唤醒但不解锁、锁定时暂停播放、用屏幕保护程序锁定、锁定时关闭屏幕，或开启**被动模式**以避免与其他蓝牙设备相互干扰。
- 使用 **立即锁定屏幕** 可立即锁定；待设备离开后重新靠近即会解锁。
- 可在内置的锁屏历史中查看近期锁定和解锁事件。
- 登录密码会安全保存在**钥匙串**中，仅在锁屏时用于模拟键盘输入解锁。可用“设置密码…”设置或更新。

需要蓝牙与辅助功能权限。BLE MAC 地址会周期性轮换的设备（多数非苹果设备）无法被可靠跟踪。

## 输入法自动化

侧边栏的**输入法**可以把 Input Source Pro 的核心工作流整合到 MacPilot：

- 使用 Carbon 枚举并切换 macOS 键盘输入源，按应用或浏览器网站的域名/URL 规则自动切换。
- 支持输入法切换时的屏幕提示、鼠标附近或屏幕中央的位置，以及菜单栏中的循环切换。
- 可按应用强制英文标点，并按应用切换标准功能键或媒体键模式。
- 全局循环快捷键为 `⌥⌘I`，也可以为具体输入法录制自定义组合键；在其他 App 中工作需要辅助功能权限。规则与其他偏好一起保存到 `config.json`。

该功能基于 macOS Carbon、Accessibility、Core Graphics 与 IOKit API 独立实现，没有打包 Input Source Pro 的源码或第三方依赖。

## 剪贴板历史

剪贴板历史会把最近复制的内容集中在一个可搜索的面板中：

- 按 `⌘⇧V` 呼出面板，可搜索，并使用方向键、回车或数字/字母快捷键粘贴或复制。
- 鼠标在某条记录上停一秒，右侧就展开它的详情（全文、大图或文件列表，加上来源应用、字符/行数、大小与复制次数），划走即收起；期间用方向键切换选中项，详情会跟着走。
- 支持固定重要条目、删除单条记录、清除未固定记录，以及设置历史数量上限。
- 支持的文本、图片、URL 等剪贴板内容会去重，并在重启后保留。

## Dock 分组

**Dock 分组**把多个应用收进一个轻量 Helper，固定到 macOS 原生 Dock 上：

- 新建分组后可以扫描已安装应用挑一个、直接把 `.app` 拖进来，或者从磁盘浏览选择；列表支持拖拽排序。
- 每个分组会在 `~/Library/Application Support/MacPilot/DockGroups/` 下生成自己的 Helper App。把这个 `.app` 拖到 Dock 上即可固定（MacPilot 不会改写 `com.apple.dock.plist`），点击它就会弹出二级列表，支持网格与列表两种布局。
- 点击列表里的应用：已在运行就直接激活，没运行才启动，绝不会启动第二个实例；正在运行的应用会显示绿点。
- 浮层页头只有分组名和一个设置齿轮（快捷键 `⌘,`），下面直接就是应用列表；没有标题栏、不产生第二个 Dock 图标、没有普通窗口边框；按 ESC 或点击外部自动关闭，支持方向键导航与 Retina。启动失败的提示显示在标题右侧，不额外占一行。
- 点开即现：点 Dock 图标的瞬间面板就出现，图标随后补齐；浮层关掉之后 Helper 会待命 5 分钟（系统也可以在内存吃紧时直接回收），这段时间内再点图标是几十毫秒的二次展开（实测 20–50 毫秒），冷启动那条 0.2 秒以上的进程启动与解析路径被整个跳过。
- 浮层永远出现在**被点的那个 Dock 图标旁边**：MacPilot 用辅助功能权限读出 Dock 上这个图标的精确位置写进 `groups.json`，浮层沿着 Dock 方向居中到**图标中心**（不是鼠标落点），垂直于 Dock 的方向紧贴 Dock 内侧；“跟随鼠标上下移动”就是这么消掉的。左边/下边/右边的 Dock 都支持。拿不到这份几何时（没给 MacPilot 辅助功能权限、分组还没固定到 Dock 上、或者 Dock 布局刚变过）自动退回“按点击位置沿 Dock 方向落点”。
- 分组图标跟随系统深浅外观：深色模式下换成压暗的底色、更柔和的强调色，浅色字形在暗底上依然清晰。
- 每个分组还有独立的**「图标外观」**偏好（默认**跟随系统**，也可固定浅色/深色），决定 Dock 上这个 Helper 图标用哪套外观出图。`.icns` 没有外观变体，所以“跟随系统”是靠**重建 Helper** 实现的：系统深浅外观一变、或用户改了这个偏好，MacPilot 就按新外观重新渲染图标并重新生成 Helper（Helper 的 Info.plist 里记录了这次用的是哪套外观，据此判断要不要重建）。注意 macOS 会缓存**已经固定在 Dock 上**的图标图像，改完之后 Dock 上如果还是旧图标，把图标从 Dock 移除再拖回来（或重新登录）就会更新。
- 设置页把两个偏好（默认布局、是否显示运行状态）收进一张设置卡片，列表上方是小节标题 + 分组/应用计数，操作按钮挂在同一行右侧；功能总开关只在首页，详情页不重复放第二个开关。
- 被管理的应用全程只读：MacPilot 只保存引用（优先 `bundleIdentifier`，路径兜底），只读取 Bundle Identifier、名称、版本、图标、可执行文件路径与运行状态。不复制、不移动、不打补丁、不注入、不重新签名第三方应用，因此应用更新、TCC 权限与代码签名都不受影响。
- 应用被移动后会显示「应用未找到」，可选择重新定位或从分组移除；缺失的应用不会被自动下载或替换。
- 应用图标只按需读取系统图标并缓存一份 PNG 缩略图（`~/Library/Caches/MacPilot/DockGroups/`，缓存键带应用版本，应用升级换图标会自动失效）；缓存随时可删，不影响任何应用。
- 删除分组只会删除 MacPilot 自己生成的 Helper 与配置，并且会先校验目标确实位于 MacPilot 自己的目录内。「清理分组数据」会一次性移除 MacPilot 自己的 Helper、配置、自定义图标与图标缓存，绝不触碰第三方应用。
- 默认关闭。关闭状态下不扫描应用、不管理 Helper、也不跑任何后台定时任务。

## 内存监控

**内存监控**在侧边栏中实时展示各软件占用的物理内存：

- 同一应用的多个进程（Helper、XPC、CLI 子进程等）会自动汇总为一条，展开可查看每个进程的明细。
- 系统内存总览提供物理内存、已使用、App 内存、联机、已压缩、已缓存文件与交换分区用量，并显示系统内存压力。
- 默认每 3 秒自动刷新，可随时暂停或手动刷新；数值口径与活动监视器「内存」列一致。

## CPU 监控

**CPU 监控**在侧边栏中实时展示各软件的 CPU 占用：

- 同一应用的多个进程会自动汇总为一条，展开可查看每个进程的 CPU 占用。
- 系统 CPU 总览提供总使用率、用户/系统/低优先级/空闲占比、逻辑核心数与 1/5/15 分钟负载。
- 默认每 3 秒自动刷新；占用率按整机逻辑核心总容量归一化，整机满载为 100%。

## 本地端口

**本地端口**页面按进程分组显示 TCP `LISTEN` 服务：

- 合并同一 PID/端口的 IPv4 与 IPv6，区分 LOCAL / LAN，并支持按端口、PID、项目、命令、用户、路径和地址搜索。
- 识别项目目录、npm 包、Python 模块、常见本地服务、`.app` 父进程和系统可执行文件。
- 打开可能的 HTTP 地址，查看进程身份、启动参数、工作目录、父进程链、运行时间以及同一 PID 监听的全部端口。
- 你启动的进程都能关闭，包括浏览器或 IDE 拉起的 dev server；只有其他用户的进程、系统自身与身份不明的进程不提供关闭。
- 关闭前会重新扫描并核对 PID、UID、可执行文件和启动时间；只发送 SIGTERM，不使用 SIGKILL、root 或特权 Helper。

只有在页面可见时才扫描；离开页面或关闭功能后会停止刷新和 favicon 请求。

## 窗口切换器

**窗口切换器**用于通过键盘快速切换不同应用的窗口：

- 按 `⌥Tab` 呼出，按住 Option 连续切换，Shift 反向切换，松开 Option 聚焦当前窗口，Escape 取消。
- 可显示应用图标、窗口标题和缩略图，也可选择包含最小化或隐藏应用的窗口。
- 可将指定应用的多个窗口合并为一个切换卡片，不改变应用实际窗口。

## 截屏与贴图

侧边栏的**截图**为 MacPilot 增加了 Snapzy 风格的截图与快捷操作：

- 按全局快捷键（默认 `F1`）进入智能元素截图；元素选择器会在鼠标停下后显示高亮，并带有防抖与自动复查，避免移动时闪屏或停在某个外层元素上。
- 截图设置页还提供区域框选、应用窗口、全屏、当前窗口、标注、OCR、滚动长截图和抠图等入口。
- 区域或应用窗口选中后会保留 PixPin 风格选区，显示八个缩放控制点、尺寸提示和悬浮工具栏；可拖动/调整选区后再复制、保存、标注、OCR、贴图或取消。
- 可直接在当前截图上添加矩形、椭圆、箭头、直线、画笔/荧光笔、模糊、聚光、序号、文字、水印和裁剪；可通过工具栏或鼠标滚轮调整粗细与透明度。
- 截图后可以自动保存到本地、复制到剪贴板、显示快捷操作预览卡片、贴图、自动打开标注编辑器、识别文字、手动上传到 GitHub/Gitee，或直接在访达中显示；自动保存可在截图设置页关闭，关闭后截图只进入剪贴板、快捷操作与贴图。
- 手动上传会显示进度、成功或错误提示，成功后将公开图片链接复制到剪贴板。
- 每个截图入口都支持在设置中修改快捷键；截图功能的全局总开关在截图设置页顶部。

所有功能都可以在各自设置页中启用或关闭。关闭后的功能不会注册全局快捷键，不会启动后台监听或定时任务，也不会出现在顶栏菜单中。例如关闭**启用截图功能**后，顶栏不会再显示任何截图菜单，同时停止截图相关后台资源占用。

## Finder 右键菜单

MacPilot 集成 Finder 扩展，在访达右键菜单中提供可配置的快捷操作：

- **复制路径**可复制所选文件和文件夹的路径。
- 使用已配置的应用打开所选项目。
- 打开终端、直接删除、隐藏或显示项目，以及通过 AirDrop 发送项目。
- 在访达空白区域的新建菜单中创建已配置的文件类型，并快速打开已配置的常用目录。
- 分别启用、禁用和排序动作、应用、新建文件类型及常用目录。

## 性能与资源占用

MacPilot 的核心取舍是轻量常驻：应用体积保持极小，常驻内存占用保持极低。它使用原生 Swift/SwiftUI 和 macOS 系统 API 构建，不携带跨平台运行时；长期数据路径也按资源上限设计，尽量避免图片和缓存持续占用内存：

- 剪贴板图片以及超过 64 KB 的内容会存储在 Application Support 目录下的文件中；历史模型只保留类型、文件名和大小等索引信息，使用时才从磁盘读取。
- 截图复制使用基于文件的延迟剪贴板提供者，只有其他应用请求 PNG 数据时才生成，请求结束后即可释放。
- 窗口切换器缩略图最大缩放到 256×160 像素，最多预取 30 个窗口；窗口清单变化时会裁剪缓存，关闭缩略图后会取消捕获任务并清空缓存。
- 快捷预览区同时最多显示 5 张卡片；关闭项目后会释放对应的面板和标注会话资源。
- 关闭某项功能后，不会继续保留对应的全局事件监听、定时器或后台任务；诊断日志在后台工具队列写入，并只保留一小时。

## 存储压缩

侧边栏的**存储压缩**会扫描指定文件夹，使用 macOS 文件系统透明压缩减少稳定文本类文件的实际磁盘占用，同时保持文件的逻辑内容不变。你可以指定后缀、最小文件大小、保持未修改的时间和最低节省比例，然后手动扫描压缩，或启用每 5 分钟一次的定期扫描。

MacPilot 会在原子替换前使用 SHA-256 校验压缩副本，并通过 macOS `ditto` 保留创建时间、修改时间及文件系统元数据。应用会跳过应用包、隐藏目录、符号链接、硬链接、稀疏文件和云端占位文件，并且只在 APFS 或 HFS+ 宗卷上工作。透明压缩后的文件仍可被其他应用直接读取，也可在同一界面恢复为未压缩文件。

## 画中画

侧边栏的**画中画**使用 ScreenCaptureKit 直接捕获单个窗口，生成跨 Space 的实时悬浮面板：

- 默认使用 `⌥⌘P` 捕获当前窗口（可在画中画设置中配置），加 `Shift` 选择窗口区域；开启快速区域后可用组合键双击直接捕获鼠标附近区域。
- 面板支持自由调整大小、保持源窗口比例、⌘ 拖动框选区域后放大、滚轮缩放、⌘+滚轮平移、`+/-` 缩放，以及跨全屏 Space 显示。
- 支持自动隐藏、单击聚焦源窗口、双击聚焦并关闭、Backspace/Esc 关闭、空格快速查看、媒体播放/暂停和方向键 seek。
- 媒体控制会匹配源 App 的真实 Now Playing 会话，支持播放/暂停、前后 5 秒、进度显示与拖动，以及 YouTube 字幕按钮。
- 支持 1–60 fps、0–100% 强度的增强对比度、多窗口模式、悬停提示、圆角，以及按 App 保存的空闲/变化/敏感检测；检测脚本可读取 `PIPIRI_EVENT`、`PIPIRI_APP`、`PIPIRI_BUNDLE_ID`、`PIPIRI_WINDOW_ID` 环境变量。
- 离屏渲染修复可用后台渲染参数重启 Chromium/Electron 应用；Firefox、Floorp、kitty、Ghostty、iTerm2 及手动选择的自定义合成器 App 可在用户确认后安装补丁。MacPilot 会完整备份原 App，支持恢复、管理员授权安装，用 FSEvents 监听更新后自动重打补丁，并在连续快速崩溃后自动恢复原版。
- 画中画配置与其他偏好一起保存在 `~/Library/Application Support/MacPilot/config.json`。

首次使用需要在“系统设置 → 隐私与安全性 → 屏幕录制”中允许 MacPilot。要在其他 App 激活时拦截全局快捷键，还需要授予 MacPilot“辅助功能”权限；没有该权限时，应用内的兼容监听仍可观察快捷键，但无法阻止原按键继续传给前台 App。自定义合成器补丁绝不会静默执行：目标 App 必须先退出，用户必须明确确认，原始 bundle 会保存在 MacPilot 的 Application Support 目录并可恢复。

## 平滑滚动

侧边栏的**平滑滚动**会把鼠标滚轮事件改写成经过插值的连续滚动帧，让滚轮手感更接近触控板。

- 可分别启用垂直/水平平滑，也可以让某个轴保持原生滚动、另一轴平滑。
- 可分别反转垂直/水平方向。
- 可调整最短步长、速度增益、持续时长和死区。
- 可选“滚轮越快加速越多”，并设置自动加速上限。
- 可选地模拟触控板的滚动/惯性阶段，兼容依赖这些字段的应用。
- 可按应用排除平滑滚动；被排除应用保留原生滚轮事件，同时仍可单独设置滚轮方向反转。
- 设置与其他功能一起写入 `config.json`；因为要读取并改写其他应用中的滚轮事件，需要辅助功能权限。

## 权限与配置

MacPilot 的规则与偏好保存在 `~/Library/Application Support/MacPilot/config.json`，更新应用不会丢失这些设置，兼容配置会自动迁移。

- **辅助功能**：用于全局快捷键、窗口切换、输入法自动化、平滑滚动、BLE 锁屏控制，以及操作其他应用。
- **屏幕录制**：用于截图、窗口缩略图和画中画；没有该权限时，窗口切换器会回退到应用图标。
- **蓝牙**：用于 BLE 解锁。登录密码保存在 macOS 钥匙串中，不会写入配置文件。

如果系统更新后仍提示没有辅助功能权限，可在“系统设置 → 隐私与安全性 → 辅助功能”中关闭再重新打开 MacPilot；权限提示中也提供**重置权限并退出**，方便重新授权。
